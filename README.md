# 出门前准备清单 (HoshiGo) 🚀

一个优雅、智能的单页 H5 应用，帮助您在出门前逐项检查必备物品。

## ✨ 特性
- **智能引导**：根据天气（下雨）和体感（寒冷）动态调整检查项。
- **状态机驱动**：严格的线性流程，防止漏项或混乱。
- **极致视觉**：采用毛玻璃特效、渐变色与平滑动画，带来极佳的用户体验。
- **移动端优先**：完美的响应式设计，适配各种尺寸的手机屏幕。
- **零依赖**：纯 HTML5 + CSS3 + Vanilla JavaScript 实现，无需任何框架，加载极快。

## 🛠️ 交互逻辑
1. 点击“我要出门”开始流程。
2. **天气确认**：询问是否下雨，决定是否带伞。
3. **体感确认**：询问是否寒冷，决定是否带外套。
4. **常规必选项**：防晒霜、防蚊水、发圈、纸巾、充电宝（必须勾选方可继续）。
5. **完成**：显示完成界面，提供重置按钮。
